# Módulo 9: Proyectos Integradores

Los ocho módulos anteriores te dieron las piezas, una por una, con mucho andamiaje: un
dataset preparado por el libro, ejercicios acotados a un solo concepto, código de ejemplo casi
listo para copiar. Este módulo final invierte esa relación: **tú decides qué técnicas aplicar
para resolver un encargo**, mientras el libro te da el contexto, los requisitos y una
estructura — no el código.

## El hilo conductor: Grano de Datos

Los primeros 18 proyectos de este módulo (todos menos el capstone final) siguen la historia de
**Grano de Datos**, una cafetería ficticia que crece a medida que tú avanzas. Al principio,
Grano de Datos es un solo local que lleva las cuentas a mano — ahí es donde tú entras, como su
primera persona de datos, mucho antes de que exista una sola línea de pandas en el proyecto.
Para cuando llegues al Nivel 5, Grano de Datos ya es una cadena de varias sucursales que
necesita pipelines de datos automatizados y un modelo que prediga qué clientes están por
dejar de comprarles.

Es el mismo universo de productos (Café, Té, Agua, Jugo) que ya reconoces de los ejemplos de
los Módulos 2 a 5 — la diferencia es que ahora **tú construyes la solución**, no solo lees
cómo se construye.

El **Proyecto 19 (Capstone)**, al cierre del módulo, rompe con Grano de Datos a propósito: es
tu proyecto, de tu elección total, pensado como pieza de portafolio profesional.

## Cómo están organizados estos 19 proyectos

Antes de empezar, el capítulo **[Historias de Usuario y Backlog](01-historias-de-usuario-backlog.md)**
te enseña el formato en el que se presenta cada proyecto — el mismo vocabulario con el que
recibirías trabajo real en un equipo de datos. Léelo primero, aunque tengas prisa por empezar
a programar: te ahorra confusión en los 19 capítulos siguientes.

Los proyectos están organizados en **6 niveles de dificultad progresiva**, cada uno con sus
requisitos previos exactos marcados en el propio capítulo:

| Nivel | Proyectos | Requiere | ¿Usa pandas? |
|-------|-----------|----------|----------------|
| 🟢 Nivel 0 — Fundamentos de Python | 1-3 | Módulo 1.1 | No — a propósito |
| 🟢 Nivel 1 — Primeros Pasos con Pandas | 4-5 | Módulo 2 | Sí, básico |
| 🟡 Nivel 2 — Limpieza, Transformación y EDA | 6-9 | Módulos 3-4 | Sí |
| 🟡 Nivel 3 — Operaciones Avanzadas | 10-12 | Módulo 5 | Sí |
| 🔴 Nivel 4 — Estadística y Machine Learning | 13-15 | Módulo 6 | Sí |
| 🔴 Nivel 5 — Producción y Dominios Especiales | 16-18 | Módulos 7-8 | Sí |
| 🔴🔴 Capstone | 19 | Todo el libro (a tu elección) | Sí |

## No esperes a terminar el libro para empezar

Esta es, quizás, la idea más importante de este módulo: **el Nivel 0 no necesita pandas en
absoluto.** Apenas termines el Módulo 1.1 (Fundamentos de Python), ya puedes intentar el
Proyecto 1 — no hace falta llegar hasta aquí, al final del libro, para tu primera victoria
real. De hecho, al cierre de cada módulo (1 a 8) encontrarás un bloque **"🚀 Pon esto en
práctica"** señalando exactamente qué proyectos de este módulo ya puedes intentar con lo que
acabas de aprender. Ve y vuelve — este módulo está diseñado para visitarse muchas veces, no
para leerse de una sola sentada al final.

## Qué deberías poder hacer al terminar este módulo

- Leer un requisito de negocio expresado como historia de usuario, y traducirlo en pasos
  técnicos concretos.
- Priorizar tu propio trabajo usando un backlog, en vez de abordar tareas en orden aleatorio.
- Resolver un problema de datos de principio a fin con las técnicas apropiadas — elegidas por
  ti, no dictadas línea por línea por el libro.
- Tener al menos un proyecto (el Capstone) listo para mostrar como pieza de portafolio
  profesional.
